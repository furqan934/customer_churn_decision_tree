# Dataset note

`customer_churn_synthetic.csv` is a synthetic dataset generated with a fixed random seed for educational use. Its rows are simulated, not actual customer records. Some values are intentionally missing to exercise imputation. The label is generated from a simulated probability model based on recency, support interactions, purchase frequency, spending, membership duration, and discount usage.

Use the dataset to learn the pipeline only. Do not make claims about real customer churn or business performance from these scores.
